# Ilustraciones para notificaciones

Generadas con el generador de imágenes integrado para esta tarea, usando la
referencia aportada por el usuario como guía visual. PNG con alfa real.

- location.png: mapa en miniatura, ruta azul y pin morado; ilustración decorativa.
- coins.png: dos pilas doradas, sin símbolos ni texto.
- completed.png: casa blanca con techo azul, plantas y destellos.
- messages.png: burbujas azul, lila y blanca, sin texto.

Se conserva el original generado dentro de `.codex/generated_images`. Estas
copias están dentro del proyecto y declaradas en pubspec.yaml. La pantalla
usa imágenes de 96 px, conservando proporciones y con decodificación limitada
para evitar cargar los originales a tamaño completo en la lista.
